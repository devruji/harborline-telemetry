## Agent skills

### Issue tracker

Issues and specs live as GitHub issues. See `docs/agents/issue-tracker.md`.

### Domain docs

Single-context layout. The technical glossary is `docs/glossary.md`. See `docs/agents/domain.md`.

### Working agreement

`dev` is the integration branch. A feature is `feat/<slug>` cut from `dev`. A bug fix is `hotfix/<slug>` cut from `dev`. Promotion from `dev` to `main` is not decided. See `docs/workflow.md`.

Failed attempts that should not be repeated are logged in `docs/trial-log.md`.

When `docs/workflow.md`, `docs/glossary.md`, `docs/trial-log.md`, or `docs/agents/*.md` change, update the matching line in this file in the same change. This file stays an index.
